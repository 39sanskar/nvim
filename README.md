# neovim for web development & software development setup guide

## Overview

Thanks for checking out my NeoVim config. Supported languages & frameworks: `typescript`, `javascript`, `python`, `golang`, `lua`, `bash`, `c`, `c++`, `json`, `yaml`, `docker`, `html`, `css`, `tailwindcss`, `rust`, `solidity`, `vue`, `react`, `svelte`

## Keymaps

- Press `Space k` (or run `:Keys`) inside Neovim to search every shortcut in plain English, e.g. "rename variable", "close file", "split screen", or a key like "space f f".
- [DOCS.md](DOCS.md) is the full cheat sheet. It's generated from `lua/keyguide/registry.lua` with `:KeysExport`.
- Files and text are searched with [fff](https://github.com/dmtrKovalenko/fff): `Space f f` finds files, `Space f g` searches text across the project.
